# 🎮 Doodle Jump Deluxe

Un jeu de plateforme vertical inspiré des jeux de type Doodle Jump, développé uniquement avec :

- HTML
- CSS
- JavaScript
- Canvas 2D
- Aucun framework
- Aucune dépendance

## ✨ Fonctionnalités

- 20 niveaux avec difficulté progressive
- Génération de plateformes
- Plateformes normales, mobiles, cassables, glacées et ressorts
- Ennemis mobiles
- Gemmes à collectionner
- 4 power-ups :
  - 🚀 Jetpack
  - 🛡️ Bouclier
  - 🧲 Aimant
  - 🌙 Gravité lunaire
- Portails
- Score + meilleur score sauvegardé dans `localStorage`
- Effets de particules
- Musique/sons synthétiques via Web Audio API
- Pause
- Contrôles clavier + boutons tactiles
- Responsive
- Aucun serveur nécessaire

## 🚀 Lancer dans VS Code

### Méthode 1 — simple

Ouvre le dossier dans VS Code puis double-clique sur `index.html`.

### Méthode 2 — recommandée

Installe l'extension VS Code **Live Server**.

Ensuite :

1. Ouvre `index.html`
2. Clic droit
3. `Open with Live Server`

## 🎮 Contrôles

- `←` / `A` : aller à gauche
- `→` / `D` : aller à droite
- `Espace` : pause
- Sur mobile : boutons tactiles

## 🌐 Mettre sur GitHub

Dans le terminal VS Code :

```bash
git init
git add .
git commit -m "Initial commit - Doodle Jump Deluxe"
git branch -M main
git remote add origin https://github.com/TON-USERNAME/doodle-jump-deluxe.git
git push -u origin main
```

Remplace `TON-USERNAME` par ton nom GitHub.

## 🌍 Publier avec GitHub Pages

Sur GitHub :

`Settings` → `Pages`

Puis :

- Source : `Deploy from a branch`
- Branch : `main`
- Folder : `/ (root)`
- Save

Ton jeu sera ensuite accessible depuis l'URL GitHub Pages de ton dépôt.
